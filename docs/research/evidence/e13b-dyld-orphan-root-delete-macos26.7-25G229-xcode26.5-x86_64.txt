   Developer directories searched: 1
     /Applications/Xcode.app/Contents/Developer
   runtime bundles of ANY kind found: 0
-- INCONCLUSIVE, and deliberately not a vote either way. Zero bundles is the TRUE answer
   on Xcode 26.x, which ships runtimes as disk images (witness 5) rather than as bundles.
   On such a machine this witness has nothing to discriminate with. It does not get to say
   'no Xcode bundles this runtime' — it did not look at any bundle. If you are on a machine
   with an older Xcode that DOES bundle runtimes, a zero here means the search is broken
   and you should stop.
