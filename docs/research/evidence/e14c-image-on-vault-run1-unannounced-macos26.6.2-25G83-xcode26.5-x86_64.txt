# mount options           apfs, local, nodev, nosuid, journaled apfs, local, nodev, nosuid, journaled
# (mount options compared with this script's own -nobrowse and 'mounted by' stripped)
# HELD EQUAL:  File System Personality=Case-sensitive APFS  Device Location=External  mount-options=apfs, local, nodev, nosuid, journaled
# VARIED:  Removable Media(Fixed->Removable)  Protocol(USB->Disk Image)
# Held equal by construction, not measured: the bytes live on /Volumes/<vault>'s device, and the
# set path is under /Volumes.

CREATED inside the image, while the identical create fails on the vault volume itself
(E14b). The discriminator is therefore among the VARIED properties above and not among
the HELD EQUAL ones — read those two lines, not this sentence.

Removable Media varied (Fixed -> Removable), so it is in the candidate set. But the
DIRECTION excludes it rather than implicating it: the volume macOS calls 'Removable' is
the one that WORKS, and the one it calls 'Fixed' is the one that FAILS. A policy
keyed on that field would have to be inverted to produce this, so the field whose name
TCC's service evokes is not what the restriction reads.

What survives in the candidate set is Protocol: a real device versus a virtual one.
That also matches E2, whose failure vanished inside images stored on this same SSD.
NOT varied by either arm, and still what H6 needs to finish: bus. A Thunderbolt
enclosure would separate 'physically removable' from 'USB'. Nothing here has done that,
so this NARROWS H6 — it does not verify it.
