==================== reading this ====================
Probes 2-5 are the answer, and they exist only because the mount and the disconnect were both
verified — an unverified run aborts and records nothing rather than reporting 'absent'.
A target that existed before the run is expected to be a plain directory after the volume goes
away: it was the mount point, and mount semantics leave it (HYPOTHESES.md H14, 2026-09-26). That
alone is not a finding. What this run adds is the SURPRISE removal: whether probes 2-5 differ from
a clean unmount — owner, mode, entries, or a mount point that is still listed — and the 'entries'
line, which shows whether anything was written into the local directory afterwards.
