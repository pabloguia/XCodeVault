                           at the control dir. 'Unreachable by either mechanism' — and
                           H14 closing as sized-but-unproducible — needs D REFUSED too,
                           with A and H1 MOUNTED. With D MOUNTED, H14 stays producible.
                           NOT 'by any privilege': Apple's own daemons mount these paths
                           (F16/E4b), and two root cells do not license that claim.
  H1 MOUNTED, D REFUSED => the CoreSimulator HIERARCHY is not what refuses; something
                           about the cache path itself is. Without H1 the A-vs-D
                           contrast cannot tell those apart.
  H1 REFUSED            => /Library/Developer/CoreSimulator/ refuses mounting
                           generally — a larger finding than 'this cache directory'.
  A REFUSED             => the session lost the ability to mount ANYWHERE before the
                           trailing control ran. C is uninterpretable and so is the
                           A-vs-D comparison. The whole run is void.
  A NOT MEASURED        => the run stopped before the trailing control, so nothing
                           establishes the session could still mount at the end. Read
                           no cell below B0.
  C NOT MEASURED        => the cache-path cell did not run; the matrix answers nothing
                           about the question it was built for.
  A MOUNTED, D REFUSED  => the refusal is specific to the CoreSimulator path rather than
                           to mount_apfs. **Read A, H1 and D together, not A and D**:
                           H1 is mount_apfs at a NEUTRAL directory inside the
                           hierarchy, so it separates 'this directory' from 'this
                           hierarchy' in a way A cannot. A+H1 MOUNTED with D REFUSED
                           is the only combination that isolates the cache directory.
  H1 NOT MEASURED       => the A/H1/D rules below cannot be applied: without the neutral
                           in-hierarchy cell, A-vs-D cannot separate 'this directory'
                           from 'this hierarchy'. Read D alone, and no further.
  A, H1 AND D MOUNTED   => nothing here refuses mount_apfs. Every REFUSED left in the
                           matrix belongs to diskutil, and the question is about
                           DiskArbitration and the VOLUME, not about the path.
