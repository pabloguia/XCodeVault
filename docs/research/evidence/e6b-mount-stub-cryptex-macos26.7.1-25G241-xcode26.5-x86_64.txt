==================== what this means for the issue #24 guard ====================
Read probes 2-4. A target that existed before the run is expected to be a plain directory after
the unmount: it was the mount point, and mount semantics leave it (HYPOTHESES.md H14,
2026-09-26). That alone is not a finding. The 'entries' line is: it shows whether anything was
written into the local directory after the volume went away.
