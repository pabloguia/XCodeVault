## 2. Raw local evidence

`defaults read com.apple.dt.Xcode | grep -iE 'Location|Archive|Compilation|DerivedData'` → only `IDEBuildLocationStyle = Shared;` (plus two unrelated `DVTSourceControlAccountURLKey` paths under DerivedData). No custom DerivedData/Archives/CompilationCache location set on this Mac.

`strings` over IDEFoundation + IDEKit + DVTFoundation (Xcode 26.5), filtered `^IDE…(Location|LocationStyle|PathOverride|ArchivesLocation|CacheLocation|DerivedData)…$`, relevant hits:
`IDEArchivePathOverride`, `IDEBuildLocationStyle`, `IDEBuildProductsLocationDeterminedByTargets`, `IDEClonedSourcePackagesDirPathOverride`, `IDECompilationCacheLocationDidChangeNotification`, `IDECustomBuildLocationType`, `IDECustomCompilationCacheLocation`, `IDECustomDerivedDataLocation`, `IDECustomDistributionArchivesLocation`, `IDECustomSnapshotsLocation`, `IDEDerivedDataDisappearedDetectionTrigger`, `IDEDerivedDataDisappearedLocation`, `IDEDerivedDataDisappearedPreceedingAction`, `IDEDerivedDataPathOverride`, `IDEDerivedDataPathOverrideDidChangeNotification`, `IDEDistributionArchivesLocationDidChangeNotification`, `IDELocationsSettingsHelper`, `IDEStandardDerivedDataLocationDidChangeNotification`, `IDEWorkspaceBuildProductsLocationDidChangeNotification`.
IDEFoundation string-table cluster (lines 9121-9125): `IDECustomDerivedDataLocation`, `IDECustomSnapshotsLocation`, `IDECustomDistributionArchivesLocation`, `IDECustomCompilationCacheLocation`, `IDECustomCompilationCacheSize`; (9159-9166): `IDEBuildLocationStyle`, `Unique`, `Shared`, `DeterminedByTargets`, `IDESharedBuildFolderName`, `IDECustomBuildLocationType`, `IDECustomBuildProductsPath`, `IDECustomBuildIntermediatesPath`; elsewhere `Legacy`, `Default`, `RelativeToWorkspace`, `Absolute`, `Custom`.
CompilationCache grep: `+[IDELocationsSettingsHelper saveCustomDerivedDataLocation:customDistributionArchivesLocation:customCompilationCacheLocation:customCompilationCacheSize:buildLocationStyle:customBuildProductsPath:customBuildIntermediatesPath:customBuildLocationType:sharedBuildFolderName:]`, `validateCustomCompilationCacheLocation:error:`, `validateCustomCompilationCacheSize:error:`, `-[IDEDeveloperPaths compilationCacheLocation]`, `_kIDECustomCompilationCacheLocation`, `-[IDEDeveloperPaths defaultDistributionArchivesLocation]`, `-[IDEDeveloperPaths defaultWorkspaceDerivedDataLocation]`. That single `save…` selector is the exact set of keys the Locations pane writes.
Note the `IDEDerivedDataDisappeared*` keys: Xcode 26 has built-in detection for a vanished DerivedData folder (relevant to the disconnected-volume failure mode).

`xcodebuild` (26.5) links `IDEFoundation.framework` (string in binary; `man xcodebuild` documents `-userdefault=value`), so any of these keys can be passed as `-Key=value` and the persisted `defaults` are honoured too.

## 3. Cross-checked probes (throwaway SwiftPM package in scratchpad, no defaults written)
- `-IDECustomDerivedDataLocation=<abs>` → `<abs>/ddprobe-<hash>/{Logs,SourcePackages,…}` created. Relative `DD_REL` → `<pkgdir>/DD_REL/ddprobe/…`. `~/DD_TILDE_PROBE` → `~/DD_TILDE_PROBE/ddprobe-<hash>/…`.
- `-IDEDerivedDataPathOverride=<abs>` and `-derivedDataPath <abs>` → identical flat layout at `<abs>/` (workspace-level override).
- `xcodebuild archive … -IDECustomDistributionArchivesLocation=<abs>` → `** ARCHIVE SUCCEEDED **`, archive at `<abs>/2026-09-06/DDProbe-Package 06-09-26, 16.35.xcarchive`; nothing written to `~/Library/Developer/Xcode/Archives`.
- `xcodebuild build COMPILATION_CACHE_ENABLE_CACHING=YES -IDECustomCompilationCacheLocation=<abs>` → `-cas-path <abs>/builtin`.
Side effects to clean up manually (not deleted per rules): `~/DD_TILDE_PROBE/` (empty DerivedData skeleton) and `~/Library/Developer/Xcode/DerivedData/ddprobe-cirggjcaiscmglhchgpbruyxpvoe/` (baseline run), plus `scratchpad/{ddprobe,DD_ABS,DD_FLAG,DD_OVERRIDE,ARCH_CUSTOM,CC_ABS,bs-baseline.txt}`.

## 4. Recommendation for XCodeVault
1. DerivedData relocation: write `IDECustomDerivedDataLocation` = **absolute POSIX path of the new root** (e.g. `/Volumes/Vault/Xcode/DerivedData`), never tilde or relative (relative silently becomes project-relative; tilde works but is ambiguous). Leave `IDEBuildLocationStyle` untouched (it is orthogonal; changing it moves Build/ out of DerivedData). To revert, delete the key (`defaults delete`), do not write the default path. Also read `WorkspaceSettings.xcsettings` per project when *discovering* where DerivedData really lives. Never touch `IDEDerivedDataPathOverride`.
2. Archives relocation: write `IDECustomDistributionArchivesLocation` = absolute path of the new Archives root (Xcode adds the date folders). Revert = delete key. Never touch `IDEArchivePathOverride`.
3. Compilation cache (Xcode ≥ 26 only, label experimental): `IDECustomCompilationCacheLocation` = absolute path; gate on Xcode version. Leave `IDECustomCompilationCacheSize` alone until its unit is determined.
4. Write with `CFPreferencesSetAppValue`/`UserDefaults(suiteName:)` for `com.apple.dt.Xcode` while Xcode is not running (Xcode caches these in-process and rewrites the plist on quit; the GUI offers a "Move" prompt when changed interactively — hostmyapple), then `CFPreferencesAppSynchronize`. All keys are honoured by both Xcode.app and `xcodebuild`, so CI on the same Mac follows automatically.
5. Caution found while researching: Apple forum thread 812321 (Jan 2026, unanswered) reports framework unit tests on "My Mac" failing when DerivedData is on an external volume (sandbox denies the volume). Add it to HYPOTHESES/EXPERIMENTS as a gating check for the DerivedData category.
