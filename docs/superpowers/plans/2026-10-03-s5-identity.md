# S5 — Visual Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give XCodeVault a logo, an app icon, a palette and one color + symbol per savings bucket, used by the app (S4) and the CLI.

**Architecture:** The SVG master lives in `Resources/Brand/`; `scripts/make-icon.sh` renders the `.icns` (committed, so CI needs no SVG renderer). Bucket color and symbol names are data on `SavingsBucket` in Core (tested, shared); the app maps them to SwiftUI in `Brand.swift`; the CLI colors bucket titles only on a TTY without `NO_COLOR`.

**Tech Stack:** SVG, `rsvg-convert` (local, for regeneration only), `iconutil`, Swift 6, SwiftUI, XCTest.

**Spec:** `docs/superpowers/specs/2026-10-03-savings-visibility-i18n-identity-design.md` §7.

## Global Constraints

- No Apple marks, no hammer, no Xcode icon (trademark). The concept: a vault door seen front-on whose dial handle leaves the door as an outward arrow — "storage, safely moved out".
- Palette: primary indigo `#2B2D6E` (background gradient `#3B3E92` → `#1C1E52`), teal: UI accent `#1FB5A8` (flat), logo arrow gradient `#17A497` → `#62E6CF`, door `#F5F7FC` → `#C7CCDF`.
- Bucket tokens (never color alone — always with the symbol and the localized title):
  | bucket | color | SF Symbol |
  |---|---|---|
  | deleteAndRegenerate | amber `#C27C12` | `arrow.counterclockwise.circle` |
  | parkExternally | blue `#3B82F6` | `shippingbox` |
  | runFromExternal | green `#22A06B` | `externaldrive.badge.checkmark` |
  | keepLocal | gray `#8A8FA3` | `internaldrive` |
- CLI color: only when stdout is a TTY, `NO_COLOR` is unset and `TERM` is not `dumb`; never in `--json`, `report`, or when piped.
- Branch `feat/identity` from `feat/cli-savings`. No push inside tasks. Swift 6, 160 columns, swift-format strict. Slow machine: focused class filters; full preflight in the last task.

import XCTest

/// The app icon ships: the plist names it, the file is in the repository, and the bundle script copies it.
final class BrandAssetTests: XCTestCase {
    private var repo: URL { URL(fileURLWithPath: #filePath).deletingLastPathComponent().deletingLastPathComponent().deletingLastPathComponent() }

    func testThePlistNamesTheIconAndTheIconExists() throws {
        let data = try Data(contentsOf: repo.appendingPathComponent("Resources/App/Info.plist"))
        let plist = try XCTUnwrap(PropertyListSerialization.propertyList(from: data, format: nil) as? [String: Any])
        XCTAssertEqual(plist["CFBundleIconFile"] as? String, "AppIcon")
        let icns = repo.appendingPathComponent("Resources/App/AppIcon.icns")
        let size = try XCTUnwrap(try FileManager.default.attributesOfItem(atPath: icns.path)[.size] as? Int)
        XCTAssertGreaterThan(size, 50_000, "an icns with every size from 16 to 1024 is well over 50 KB")
        let head = try FileHandle(forReadingFrom: icns).read(upToCount: 4)
        XCTAssertEqual(head, Data("icns".utf8))
    }

    func testTheBundleScriptCopiesTheIcon() throws {
        let script = try String(contentsOf: repo.appendingPathComponent("scripts/bundle-app.sh"), encoding: .utf8)
        XCTAssertTrue(script.contains("Resources/App/AppIcon.icns"), "bundle-app.sh must copy the icon into Contents/Resources")
    }

    func testTheLogoHasNoAppleMarks() throws {
        let svg = try String(contentsOf: repo.appendingPathComponent("Resources/Brand/logo.svg"), encoding: .utf8)
        for word in ["apple", "xcode", "hammer"] { XCTAssertFalse(svg.lowercased().contains(word), word) }
    }
}

- [ ] **Step 3: `scripts/make-icon.sh`**

```bash
#!/usr/bin/env bash
# Renders Resources/Brand/logo.svg into Resources/App/AppIcon.icns and docs/brand/logo-256.png.
# Needs rsvg-convert (brew install librsvg) and iconutil; the outputs are committed, so CI never runs this.
set -euo pipefail
cd "$(dirname "$0")/.."
command -v rsvg-convert >/dev/null || { echo "make-icon: rsvg-convert not found (brew install librsvg)" >&2; exit 2; }
work=$(mktemp -d -t xcv-icon); trap 'rm -rf "$work"' EXIT
set_dir="$work/AppIcon.iconset"; mkdir -p "$set_dir"
for size in 16 32 128 256 512; do
    rsvg-convert -w "$size" -h "$size" Resources/Brand/logo.svg -o "$set_dir/icon_${size}x${size}.png"
    rsvg-convert -w $((size * 2)) -h $((size * 2)) Resources/Brand/logo.svg -o "$set_dir/icon_${size}x${size}@2x.png"
done
iconutil -c icns "$set_dir" -o Resources/App/AppIcon.icns
mkdir -p docs/brand
rsvg-convert -w 256 -h 256 Resources/Brand/logo.svg -o docs/brand/logo-256.png
echo "make-icon: wrote Resources/App/AppIcon.icns and docs/brand/logo-256.png"
```

`logo-mono.svg`: the same geometry, single color `#2B2D6E` on transparent, the tile removed (for light backgrounds and print). Run `scripts/make-icon.sh`. Info.plist: `<key>CFBundleIconFile</key><string>AppIcon</string>`. `bundle-app.sh`: next to the existing resource copies, `cp Resources/App/AppIcon.icns "$APP/Contents/Resources/AppIcon.icns"`.
