# S3 — Savings-first CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `xcodevaultctl` answer "how much can I reclaim, temporarily and permanently, and what do I run" in five languages, with help that is grouped by task, carries examples, and keeps the experimental label in every language.

**Architecture:** Rendering and planning live in Core and are tested there (`TextRenderer.savings`, `SavingsPlanner`); the CLI only wires them. Byte counts follow `L10n.locale`. Help abstracts come from the catalog through one helper that prefixes the localized experimental label; `configuration` becomes a computed `static var` so the label can be tested in every locale on the rendered help.

**Tech Stack:** Swift 6, SwiftPM, swift-argument-parser 1.8.2 (`CommandGroup`, `groupedSubcommands`), XCTest, the S2 `L10n` layer and `scripts/l10n.sh`.

**Spec:** `docs/superpowers/specs/2026-10-03-savings-visibility-i18n-identity-design.md` — §5, §5.1 (amendment), §10 (carry-overs), §3.4 and §4.6 (binding amendments).

## Global Constraints

- Branch `feat/cli-savings`, created from `feat/savings-i18n`. No push inside tasks.
- `--json` output is never localized and stays byte-identical across locales (tests exist; extend them, never weaken).
- Every new user-facing string goes through `L10n.tr("cli.…")` / `L10n.plural` with a **literal** key; keys namespaced `cli.*` (CLI-only) or `savings.*` (shared). Non-English values ship `needs_review`. Glossary (spec §4.6): command words, flags and ids stay untranslated where typed; concepts are translated in prose.
- Rule 10: every command whose strategy is experimental keeps the localized experimental label at the start of its abstract, in every locale. Rule 5: nothing here offers Archives for deletion.
- Read commands never change anything (spec §5.1): no cache files.
- Tests that assert English text call `L10n.configure(override: "en", environment: [:], preferred: [])` first; tests that switch locale restore "en" in `tearDown`.
- Swift 6, macOS 14+, 4-space indent, 160 columns, `swift format lint --strict`. After any catalog edit: `scripts/l10n.sh gen && scripts/l10n.sh check`.
- Slow machine: focused `swift test --filter`, confirm "Executed N tests" with N > 0; one full `scripts/preflight.sh` in the last task.

```swift
@testable import XCodeVaultCore

/// Spec §5.1: a run in English prints `10.37 GB` on any machine, whatever its region settings.
final class ByteCountLocaleTests: XCTestCase {
    override func tearDown() { L10n.configure(override: "en", environment: [:], preferred: []) }

    func testTheSeparatorFollowsTheChosenLanguageNotTheMachine() {
        XCTAssertTrue(ByteCount.format(10_370_000_000, locale: "en").contains("10.37"), ByteCount.format(10_370_000_000, locale: "en"))
        XCTAssertTrue(ByteCount.format(10_370_000_000, locale: "pt-BR").contains("10,37"), ByteCount.format(10_370_000_000, locale: "pt-BR"))
        XCTAssertTrue(ByteCount.format(10_370_000_000, locale: "es").contains("10,37"), ByteCount.format(10_370_000_000, locale: "es"))
    }

    func testTheUnsignedOverloadUsesTheProcessLocale() {
        L10n.configure(override: "pt-BR", environment: [:], preferred: [])
        XCTAssertEqual(ByteCount.format(UInt64(10_370_000_000)), ByteCount.format(10_370_000_000, locale: "pt-BR"))
        L10n.configure(override: "en", environment: [:], preferred: [])
        XCTAssertEqual(ByteCount.format(UInt64(10_370_000_000)), ByteCount.format(10_370_000_000, locale: "en"))
    }

    func testZeroIsANumberNotAWord() {
        // The old formatter had `allowsNonnumericFormatting = false`: "Zero KB" must not appear in any language.
        for locale in L10n.supportedLocales { XCTAssertTrue(ByteCount.format(0, locale: locale).contains("0"), locale) }
    }

    func testUnitsAreDecimalLikeFinder() {
        XCTAssertTrue(ByteCount.format(1_000_000_000, locale: "en").hasPrefix("1"), "1 GB, not 0.93 GiB")
    }
}
```

- [ ] **Step 2:** `swift test --filter ByteCountLocaleTests` → build failure (no `format(_:locale:)`).

- [ ] **Step 3: Implement**

```swift
import Foundation

public enum ByteCount {
    public static func format(_ bytes: UInt64) -> String { format(Int64(clamping: bytes)) }
    public static func format(_ bytes: Int64) -> String { format(bytes, locale: L10n.locale) }

    /// Decimal units (GB), matching Finder and diskutil, in `locale`'s number format — never the machine's region
    /// (spec §5.1). Zero is written as a number.
    public static func format(_ bytes: Int64, locale: String) -> String {
        bytes.formatted(
            .byteCount(style: .file, allowedUnits: .all, spellsOutZero: false, includesActualByteCount: false)
                .locale(Locale(identifier: locale)))
    }
}
```

- [ ] **Step 4:** focused test passes. Then `swift test --filter "DoctorAndScanTests|GrantedToolsTests|CLILanguageTests"` — existing callers. If an existing test pinned an exact English byte string that changed (e.g. `"Zero KB"` → `"0 bytes"`), report it with old/new values rather than editing the expectation.

**Interfaces:**
- Produces:

```swift
public struct SavingsPlanRow: Sendable, Codable, Equatable {
    public let categoryID: String
    public let categoryName: String
    /// Boot-volume bytes counted for this category (0 for an option that only redirects new data).
    public let bytes: UInt64
    public let option: SavingsOption
    /// The command the user runs; `<angle brackets>` are values they supply. Never translated.
    public let command: String
}

public enum SavingsPlanner {
    /// One row per category offering `bucket`, largest first; categories whose option only redirects new data are
    /// listed with 0 bytes. Counts the same items as `SavingsCalculator` (exists, not a symlink, on the boot volume,
    /// not a breakdown).
    public static func rows(report: ScanReport, bucket: SavingsBucket) -> [SavingsPlanRow]
    /// The command for a (category, bucket) pair; nil when the pair is not offered.
    public static func command(categoryID: String, bucket: SavingsBucket) -> String?
}
```

Command table (verify each flag against the command's declaration in `Sources/xcodevaultctl/` before writing it; if one differs, use the real spelling and say so in the report):

| category | bucket | command |
|---|---|---|
| any with `.safeCleanup` | delete | `xcodevaultctl clean --category <id> --apply` (the literal id) |
| `simulatorRuntimeAssets` | delete | `xcodevaultctl runtime delete <identifier> --yes` |
| `simulatorDevices` | delete | `xcrun simctl delete <udid>` |

- when there are no rows: `cli.plan.empty` ("Nothing on this Mac offers this option.").
`--json` prints `[SavingsPlanRow]` (not localized). Abstract: `cli.cmd.plan.abstract` = "Read-only. What to run to reclaim space one way: delete, park, or run from an external drive." (not experimental; individual rows carry the marker).
